1. El Reparto de los Camellos (Capítulo III)

📖 Descripción del Capítulo

Tres hermanos debían repartirse una cantidad de camellos según fracciones específicas (1/2, 1/3 y 1/9). Como el total original no era divisible de forma exacta, Beremiz añadía un camello prestado para facilitar el reparto, beneficiando a todos y obteniendo una ganancia. ¡Ahora puedes probar ingresando cualquier cantidad de camellos!

⚡ Algoritmo

  1. Ingresar la cantidad deseada de camellos de la herencia.
  2. Sumar 1 camello auxiliar para ajustar la división.
  3. Calcular la mitad (1/2), la tercera parte (1/3) y la novena parte (1/9) del nuevo total.
  4. Determinar el sobrante final para Beremiz.

📥 Entrada de Datos (Libre)

📤 Salida de Datos

Ingresa un número y presiona "Calcular Reparto"...

2. El Reparto de las Monedas por los Panes (Capítulo IV)

📖 Descripción del Capítulo

Dos viajeros llevaban panes diferentes y los compartieron equitativamente con un jeque, quien al llegar a Bagdad pagó con monedas de oro. Mediante proporciones matemáticas exactas basadas en los trozos aportados y consumidos, se calcula el pago justo para cada uno. ¡Introduce los panes que desees!

⚡ Algoritmo

  1. Ingresar los panes aportados por el primer y segundo viajero.
  2. Multiplicar cada pan por 3 para obtener los trozos totales (asumiendo partición en tercios).
  3. Calcular el consumo equitativo de los 3 comensales.
  4. Restar el consumo individual a los trozos aportados para hallar la contribución neta y asignar las monedas.

3. Ejercicio 12: Raíces de una Ecuación Cuadrática ($ax^2 + bx + c = 0$)

📖 Descripción

Determina las raíces reales de una ecuación cuadrática ingresando los coeficientes $a$, $b$ y $c$. El programa calcula el discriminante $D = b^2 - 4ac$ y evalúa si tiene dos raíces, una raíz o no tiene raíces reales.

⚡ Algoritmo

  1. Recibir los valores de $a$, $b$ y $c$.
  2. Calcular el discriminante $D = b^2 - 4ac$.
  3. Si $D > 0$, calcular dos raíces reales distintas.
  4. Si $D = 0$, calcular una raíz real única.
  5. Si $D < 0$, indicar que no existen raíces reales.

4. Ejercicio 13: Estimación de $\pi$ mediante Serie con Bucle

📖 Descripción

Estima el valor de $\pi$ utilizando la expresión matemática mediante un bucle para un número de términos $n$ dado (por ejemplo, 100, 10000 o 1000000) y compara el resultado con el valor real de $\pi$.

⚡ Algoritmo

  1. Ingresar el valor de iteraciones $n$.
  2. Utilizar un bucle desde $1$ hasta $n$ acumulando la suma de $1 / n^2$.
  3. Multiplicar el resultado total por $6$ y aplicar la raíz cuadrada.
  4. Comparar el valor obtenido con $\pi$ ($\text{Math.PI}$).
